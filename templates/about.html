PROJECT OVERVIEW

Learn to recognise
phishing signals.

PhishGuard is a defensive, local-only demonstration for cybersecurity learning.

What it demonstrates

  • Rule-based analysis of email wording.
  • Basic URL structure and hostname checks.
  • Risk scoring with explainable findings.
  • Practical safety recommendations.

Limitations

This project does not use machine learning, threat-intelligence feeds, DNS reputation, browser isolation, or live website inspection. Attackers can evade simple keyword rules. Results are educational indicators, not a definitive classification.

Ethical scope

No real phishing messages are sent, no credentials are collected, and no external website is contacted. Use only sample data or content you are authorised to analyse.
